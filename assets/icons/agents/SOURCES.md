# Agent artwork

Kwork bundles the marks for offline identification. Each runtime, its registered aliases and its settings entry share one asset. A custom local profile receives a generic terminal symbol, including when its author names it after a vendor.

## Marks supplied through the Agent Client Protocol registry

The files below are the publisher entries in [registry revision bd59518](https://github.com/agentclientprotocol/registry/tree/bd59518f936381f421bab6c289ddecd3af6d9235). Each link opens the corresponding directory with its publisher metadata and SVG. The vectors are unchanged. The desktop renderer supplies the foreground color for SVGs using `currentColor`. The registry's [Apache 2.0 license](LICENSE-ACP) accompanies these files.
